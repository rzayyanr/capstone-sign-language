# Prompt Ikon Gaya Duolingo (Isyarat)

Gaya visual: **ikon kartun flat 2D ala aplikasi belajar bahasa** — tebal, bulat,
ramah, warna solid cerah, outline gelap tebal, tanpa gradasi/3D, latar putih polos.
Bukan tiruan Duo si burung; ikon bertema tangan isyarat & edukasi.

## Template umum

```
Flat cartoon app icon of [SUBJEK], Duolingo-style playful rounded thick outline,
bold friendly mascot illustration style, [POSISI/AKSI], solid vibrant [WARNA UTAMA]
fill with thick dark [WARNA OUTLINE] outline, simple clean minimal, centered on
plain solid white background, no gradients, no shading, no 3D, no photorealism,
no text, no watermark --no realistic skin, wrinkles, extra fingers, deformed
hand, text, watermark
```

Warna outline konsisten: terracotta/cokelat tua `#5b3a29` (senada outline tangan).
Warna isi: peach hangat untuk tangan, teal `#0e7a6c` untuk elemen aksi, amber
untuk cahaya/energi.

# Prompt Visual Abjad SIBI (B sampai Y)

Gaya visual mengikuti gambar huruf A yang sudah kamu pilih: ilustrasi vektor 2D flat, warna kulit peach hangat, outline terracotta tebal, latar putih polos, tanpa gradasi dan bayangan.

## Cara pakai

1. Salin satu prompt utuh (termasuk bagian `--no ...` di akhir) ke AI image generator kamu (ChatGPT, DALL-E, Midjourney, Bing Image Creator, Recraft, dll).
2. Generate satu per satu, per huruf.
3. Simpan hasilnya sebagai PNG dengan nama file sesuai huruf: `B.png`, `C.png`, dst.
4. Kirim gambarnya ke Hermes lewat chat (atau simpan langsung ke `app/public/assets/letters/`), nanti dicek akurasi gesturnya lalu dipasang ke aplikasi.

Catatan: total ada 23 huruf statis tersisa (B, C, D, E, F, G, H, I, K, L, M, N, O, P, Q, R, S, T, U, V, W, X, Y). Huruf J dan Z tidak dipakai di MVP karena gesturnya bergerak (dinamis).
